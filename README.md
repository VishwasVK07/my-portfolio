# Portfolio Website (Practice Project)

A simple, single-page website built to practice fundamental front-end web development. This project was created as a hands-on learning exercise to get experience structuring a webpage, applying styles, and adding basic interactivity, rather than as a deployment of my actual professional experience.

## Technologies Used
*   **HTML5:** For page structure, navigation links, and content organization.
*   **CSS3:** For layout design, custom styling, and interactive hover effects.
*   **JavaScript:** For basic dynamic elements and DOM manipulation.

## How to View
1. Clone or download this repository.
2. Open the `index.html` file directly in any web browser.
